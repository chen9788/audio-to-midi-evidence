# Audio to MIDI evidence
This repository contains small, reproducible fixtures and observed MIDI event counts for browser-based audio-to-MIDI experiments. The CSV records the generated melody and silent control used in the published workflow.
The companion tool is available at https://mp3frommidi.com/ . The site explains supported MP3/WAV inputs and documents where mixed or overlapping audio can lose notes.
## Files
- `fixtures.csv` — input type, expected and observed event counts, and observed pitches.
These are controlled fixtures, not accuracy claims for arbitrary recordings.
